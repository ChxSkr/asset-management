数字资产管理系统

Digital Asset Management System

项目答辩报告

Spring Boot 3 + Vue 3 全栈项目  |  2026年5月

项目背景与目标

背景

企业/团队在日常工作中产生大量数字文件（文档、图片、视频等），缺乏统一的存储、分类、检索和版本管理能力，导致文件查找困难、版本混乱、协作低效。

目标

构建一个安全、高效、易用的数字资产管理系统，实现文件集中存储、多维度检索、版本追溯、权限管控，提升团队数字资产管理效率。

技术选型

后端

Spring Boot 3.2.5 MyBatis-Plus 3.5.6 Spring Security JWT 0.12.5 MySQL 8.0 Maven BCrypt

前端

Vue 3.5 Composition API Pinia 3.0 Element Plus 2.14 Vue Router 4 Vite 8 Axios

系统架构

Vue 3 前端 — Element Plus UI — Axios HTTP 请求

⬇

JWT 拦截器 — Token 验证 — 角色解析 — 注入 userId/role

⬇

Controller → Service → Mapper (MyBatis-Plus) → MySQL

⬇

MySQL 8.0 — 8 张表 — 文件存储在本地磁盘

数据库设计

表名说明核心字段
user用户表username, password(BCrypt), role, status
asset资产表asset_name, file_type, file_size, is_deleted
category分类表category_name, parent_id(树形结构)
tag标签表tag_name(唯一约束)
asset_tag资产-标签关联asset_id + tag_id (多对多)
asset_version版本表version_number, storage_path, version_note
operation_log操作日志operation_type, description, ip_address
download_log下载日志asset_id, user_id, ip_address

核心功能（一）

🔐

用户认证与权限

JWT Token 认证，BCrypt 密码加密，管理员/普通用户角色隔离，接口级权限拦截

📁

资产管理

文件上传(类型校验+大小限制)、分页列表、多条件筛选、详情查看、在线下载

🔄

版本管理

同一资产支持多次上传新版本，自动递增版本号，版本历史追溯，操作日志记录

核心功能（二）

🗂️

分类与标签

无限级树形分类管理，标签灵活关联，筛选时按标签实时过滤，标签关联资产数动态统计

🗑️

回收站机制

软删除保障数据安全，回收站可查看已删除资产，支持一键恢复和彻底永久删除

🔍

全局搜索

关键词全文搜索，支持按分类、文件类型、标签、日期范围多维度组合筛选

功能亮点

文件类型智能分类筛选（PDF/DOC/IMAGE/VIDEO/AUDIO/ZIP/OTHER）
标签关联资产数实时计算
分类树构建（递归算法）
软删除 + 回收站 + 永久删除三级删除机制
操作日志自动记录（UPLOAD/UPDATE/DELETE/RESTORE/PERMANENT_DELETE）
下载日志追踪（用户+资产+IP+时间）
深色/浅色主题一键切换（CSS变量 + Pinia状态持久化）
可折叠侧边栏 + 面包屑导航
上传文件白名单校验 + 大小限制
JWT拦截器全局鉴权 + 角色级权限
统一Result响应格式 {code, message, data, timestamp}
全局异常处理（GlobalExceptionHandler）
